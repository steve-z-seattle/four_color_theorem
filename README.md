# The Four Color Theorem

     This repository contains two presentation files (`present5` and `present6`), or
     certificates, that were missing from the RSST repository. Together with the other
     presentation files from RSST, they form a complete set of discharging certificates
     for the Four Color Theorem.

     ## Verification

     To verify these files, use RSST's `discharge` program with its original set of
     633 configurations and 32 discharging rules. Both files pass verification.
     Together with the remaining RSST certificates, they complete the discharging
     portion of the machine-verified proof of the Four Color Theorem.

     **Note:** These two files were adapted from Steinberger's files. In particular,
     `present6` required substantial modifications before it could pass verification.
